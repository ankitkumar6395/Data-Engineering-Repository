# 📅 Day 6 — Python Strings Completed ✅
 
### Q1. 📝 What is a string in Python?
 
**Answer:** A string is a sequence of characters used to store text, such as employee names, email addresses, and department names.
 
employee\_name \= "Ankit Kumar"
print(employee\_name)
 
```
employee_name = "Ankit Kumar"
print(employee_name)
```
 
### Q2. 🔍 How do you convert a string to lowercase or uppercase?
 
**Answer:** Use `lower()` to convert text to lowercase and `upper()` to convert it to uppercase.
 
department \= "DATA ENGINEERING"
 
print(department.lower())
print(department.upper())
 
```
department = "DATA ENGINEERING"
print(department.lower())
print(department.upper())
```
 
### Q3. 🧹 What is the purpose of `strip()`?
 
**Answer:** The `strip()` method removes whitespace from the beginning and end of a string.
 
name \= "  Ankit Kumar  "
print(name.strip())
 
```
name = "  Ankit Kumar  "
print(name.strip())
```
 
### Q4. 🔄 What does the `replace()` method do?
 
**Answer:** It replaces occurrences of a specified substring with another substring.
 
file\_name \= "sales\_old.csv"
print(file\_name.replace("old", "new"))
 
```
file_name = "sales_old.csv"
print(file_name.replace("old", "new"))
```
 
### Q5. ✂️ What is the purpose of `split()`?
 
**Answer:** The `split()` method divides a string into a list of substrings using a separator.
 
record \= "101,Ankit,45000"
print(record.split(","))
 
```
record = "101,Ankit,45000"
print(record.split(","))
```
 
### Q6. 🔢 What is string indexing?
 
**Answer:** String indexing accesses an individual character using its position. Positive indexing starts at `0`, while negative indexing starts from the end.
 
name \= "Python"
print(name\[0])
print(name\[-1])
 
```
name = "Python"
print(name[0])
print(name[-1])
```
 
### Q7. ✂️ What is string slicing?
 
**Answer:** Slicing extracts a portion of a string using the syntax `string[start:stop]`. The stop index is excluded.
 
file\_name \= "sales\_report.csv"
print(file\_name\[0:5])
 
```
file_name = "sales_report.csv"
print(file_name[0:5])
```
 
### Q8. 📧 How can you perform basic email validation?
 
**Answer:** You can use simple string checks to verify that an email contains `@` and a dot after it. This is only basic validation, not a complete email-format check.
 
email \= "ankit@example.com"
 
if "@" in email and "." in email.split("@")\[-1]:
print("Basic email check passed")
else:
print("Invalid email format")
 
```
email = "ankit@example.com"
if "@" in email and "." in email.split("@")[-1]:
	print("Basic email check passed")
else:
	print("Invalid email format")
```
 
### Q9. 🔎 What do `startswith()` and `find()` do?
 
**Answer:** `startswith()` checks whether a string begins with a specified value. `find()` returns the position of a substring or `-1` if it is not found.
 
file\_name \= "sales.csv"
 
print(file\_name.startswith("sales"))
print(file\_name.find(".csv"))
 
```
file_name = "sales.csv"
print(file_name.startswith("sales"))
print(file_name.find(".csv"))
```
 
### Q10. ⚙️ How are strings useful in Data Engineering?
 
**Answer:** Strings are useful for cleaning text fields, standardizing names, processing file names, checking basic data formats, and preparing text data for ETL pipelines.

# 📅 Day 7 — Python Lists Completed ✅
 
### Q1. 📋 What is a list in Python?
 
**Answer:** A list stores multiple items in a single variable. Lists are ordered, mutable, and allow duplicate values.
 
files \= \["sales.csv", "orders.csv", "customers.csv"]
print(files)
 
```
files = ["sales.csv", "orders.csv", "customers.csv"]
print(files)
```
 
### Q2. 🔍 What is the difference between indexing and slicing?
 
**Answer:** Indexing accesses one element, while slicing extracts a range of elements.
 
files \= \["sales.csv", "orders.csv", "customers.csv"]
 
print(files\[0])
print(files\[0:2])
 
```
files = ["sales.csv", "orders.csv", "customers.csv"]
print(files[0])
print(files[0:2])
```
 
### Q3. ➕ What is the difference between `append()` and `extend()`?
 
**Answer:** `append()` adds one item to a list. `extend()` adds each item from an iterable.
 
files \= \["sales.csv"]
files.append("orders.csv")
files.extend(\["customers.csv", "payments.csv"])
 
print(files)
 
```
files = ["sales.csv"]
files.append("orders.csv")
files.extend(["customers.csv", "payments.csv"])
print(files)
```
 
### Q4. 🗑️ What is the difference between `remove()` and `pop()`?
 
**Answer:** `remove()` deletes the first matching value, while `pop()` removes and returns an element by index. Without an index, `pop()` removes the last element.
 
numbers \= \[10, 20, 30, 40]
 
numbers.remove(20)
removed \= numbers.pop()
 
print(numbers)
print(removed)
 
```
numbers = [10, 20, 30, 40]
numbers.remove(20)
removed = numbers.pop()
print(numbers)
print(removed)
```
 
### Q5. 🔢 How do you count the number of items in a list?
 
**Answer:** Use the built-in `len()` function.
 
files \= \["sales.csv", "orders.csv", "customers.csv"]
print(len(files))
 
```
files = ["sales.csv", "orders.csv", "customers.csv"]
print(len(files))
```
 
### Q6. 🔎 How do you check whether a value exists in a list?
 
**Answer:** Use the `in` membership operator.
 
files \= \["sales.csv", "orders.csv"]
 
print("sales.csv" in files)
print("customers.csv" in files)
 
```
files = ["sales.csv", "orders.csv"]
print("sales.csv" in files)
print("customers.csv" in files)
```
 
### Q7. 🔃 How do you sort a list in ascending or descending order?
 
**Answer:** Use `sort()` for ascending order and `sort(reverse=True)` for descending order. The method modifies the original list.
 
priorities \= \[2, 5, 1, 4, 3]
 
priorities.sort()
print(priorities)
 
priorities.sort(reverse\=True)
print(priorities)
 
```
priorities = [2, 5, 1, 4, 3]
priorities.sort()
print(priorities)
priorities.sort(reverse=True)
print(priorities)
```
 
### Q8. 🗂️ What is a list of dictionaries?
 
**Answer:** It is a list containing dictionaries, where each dictionary can represent one structured record, such as an employee.
 
employees \= \[
{"id": 101, "name": "Ankit", "salary": 45000},
{"id": 102, "name": "Priya", "salary": 55000}
]
 
print(employees\[0]\["name"])
 
```
employees = [
	{"id": 101, "name": "Ankit", "salary": 45000},
	{"id": 102, "name": "Priya", "salary": 55000}
]
print(employees[0]["name"])
```
 
### Q9. ⚙️ How can you remove duplicate file names while preserving order?
 
**Answer:** Loop through the original list and append a file only when it has not already been added to the result.
 
files \= \["sales.csv", "orders.csv", "sales.csv"]
unique\_files \= \[]
 
for file in files:
if file not in unique\_files:
unique\_files.append(file)
 
print(unique\_files)
 
```
files = ["sales.csv", "orders.csv", "sales.csv"]
unique_files = []
for file in files:
	if file not in unique_files:
		unique_files.append(file)
print(unique_files)
```
 
### Q10. 🚀 How are Python lists useful in Data Engineering?
 
**Answer:** Lists can store file queues, hold batches of records, filter data, detect duplicate values, and support basic data-quality checks. For very large datasets, memory-efficient or distributed tools may be more appropriate.

# 🐍 Day 8 – Python Tuples and Sets Completed ✅

## 🎯 Interview Questions and Answers

### Q1. 📦 What is a tuple in Python?

**Answer:** A tuple is an ordered collection of elements that cannot be modified after creation. It allows duplicate values and supports indexing.

```
required_columns = ("employee_id", "name", "salary")

print(required_columns)
print(required_columns[0])
```

### Q2. 🔒 Why are tuples immutable?

**Answer:** Tuples are immutable because their elements cannot be reassigned after the tuple is created. They are useful for storing fixed information, such as required column names and configuration settings.

### Q3. 🧹 What is a set in Python?

**Answer:** A set is a collection of unique elements. It automatically removes duplicate values and does not support indexing.

```
file_types = {"csv", "json", "csv", "parquet"}

print(file_types)
```

### Q4. ⚖️ What is the difference between a list, tuple, and set?

**Answer:**

|Feature|List|Tuple|Set|
|---|---|---|---|
|Ordered|Yes|Yes|No positional order|
|Mutable|Yes|No|Yes|
|Duplicates|Allowed|Allowed|Not allowed|
|Indexing|Supported|Supported|Not supported|
|Common use|Modifiable records|Fixed collections|Unique values|

### Q5. ⚙️ Why are sets useful in Data Engineering?

**Answer:** Sets help remove duplicates, compare database schemas, identify missing columns, and track unique file names or transaction IDs.

### Q6. ➕ What is the difference between `add()` and `update()`?

**Answer:** `add()` inserts one element into a set, while `update()` adds multiple elements from an iterable.

```
processed_files = {"sales.csv"}

processed_files.add("orders.csv")
processed_files.update(["customers.csv", "payments.csv"])

print(processed_files)
```

### Q7. 🔗 What is the difference between `union()` and `intersection()`?

**Answer:** `union()` returns all unique elements from both sets. `intersection()` returns only the elements common to both sets.

```
source_a = {"sales.csv", "orders.csv"}
source_b = {"orders.csv", "customers.csv"}

print(source_a.union(source_b))
print(source_a.intersection(source_b))
```

### Q8. 🔍 What does the `difference()` method do?

**Answer:** The `difference()` method returns elements present in the first set but absent from the second set.

```
required_columns = {"employee_id", "name", "salary"}
received_columns = {"employee_id", "name", "department"}

missing_columns = required_columns.difference(received_columns)

print(missing_columns)
```

### Q9. 🗑️ How do you remove an element from a set?

**Answer:** Use `remove()` or `discard()`. The `remove()` method raises a `KeyError` if the element does not exist, while `discard()` does not raise an error in that case.

```
files = {"sales.csv", "orders.csv"}

files.discard("customers.csv")
files.remove("orders.csv")

print(files)
```

### Q10. 🔐 Can a set contain duplicate values?

**Answer:** No. A set stores each unique element only once. If duplicate values are added, the set retains only one occurrence.

```
transaction_ids = {1001, 1002, 1001, 1003}

print(transaction_ids)
```

### Q11. 🧩 How can you check whether one set is a subset of another?

**Answer:** Use `issubset()` to check whether every element of one set exists in another set.

```
required_permissions = {"read", "write"}
available_permissions = {"read", "write", "monitor"}

print(required_permissions.issubset(available_permissions))
```

### Q12. 🚀 How can tuples and sets work together in an ETL pipeline?

**Answer:** A tuple can store fixed required column names, while sets can compare those columns with incoming data to identify missing or unexpected columns. Together, they can support basic schema validation before data processing.

```
required_columns = ("employee_id", "name", "salary")
received_columns = {"employee_id", "name", "department"}

missing = set(required_columns) - received_columns
unexpected = received_columns - set(required_columns)

print("Missing columns:", missing)
print("Unexpected columns:", unexpected)
```
