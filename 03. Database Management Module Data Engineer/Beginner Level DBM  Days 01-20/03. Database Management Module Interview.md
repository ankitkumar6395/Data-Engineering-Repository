# Day 1: Introduction to Python for Data Engineering Completed ✅
### Q1. What is Python?
Python is a high-level, general-purpose programming language used for automation, data processing, and application development.
 
### Q2. Why is Python useful for Data Engineers?
It helps build ETL pipelines, process data, automate tasks, and connect to databases and APIs.
### Q3. What is an ETL pipeline?
 ETL is a process that extracts data from sources, transforms it into a suitable format, and loads it into a target system.
 
### Q4. What is Jupyter Notebook? 
Jupyter Notebook is an interactive environment where code, explanations, and output can be organised in separate cells.
 
### Q5. What is the difference between a variable and a data type?
A variable is a name that refers to a value, while a data type defines the kind of value, such as text, integer, or decimal.
