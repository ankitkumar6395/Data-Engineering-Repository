# 🗄️ Day 1 — Introduction to PostgreSQL and pgAdmin

## 🎯 Learning Objectives

- Understand database fundamentals.
    
- Learn the difference between a DBMS and an RDBMS.
    
- Understand PostgreSQL and pgAdmin.
    
- Learn about tables, rows, columns, schemas, and SQL.
    
- Create a database and table.
    
- Insert and retrieve records.
    

##  📌 1. What Is Data?

Data consists of facts, figures, or observations.

Examples:

- Employee names
    
- Customer email addresses
    
- Product prices
    
- Order dates
    
- Sales amounts
    

## 🗄️ 2. What Is a Database?

A database is an organized collection of data that can be stored, retrieved, updated, and managed efficiently.

**Example:** A company database may contain employee, department, customer, and sales information.

## ⚙️ 3. What Is a DBMS?

A Database Management System (DBMS) is software used to create, manage, retrieve, update, and maintain databases.

### Main responsibilities

- Data storage and retrieval
    
- Access control
    
- Data integrity
    
- Backup and recovery
    
- Managing concurrent access
    

## 🔗 4. What Is an RDBMS?

A Relational Database Management System (RDBMS) stores data in tables consisting of rows and columns.

Examples:

- PostgreSQL
    
- MySQL
    
- Microsoft SQL Server
    
- Oracle Database
    

Tables can be related using keys such as primary keys and foreign keys.

## 🐘 5. What Is PostgreSQL?

PostgreSQL is an open-source relational database management system.

### Key features

- Supports SQL queries.
    
- Supports transactions and constraints.
    
- Provides indexes for improving data access.
    
- Supports complex queries and joins.
    
- Supports JSON and JSONB.
    
- Provides features for security and data integrity.
    

### Common use cases

- Web applications
    
- Business databases
    
- Reporting and analytics
    
- Data engineering workflows
    
- Data warehouses and operational data systems
    

## 🖥️ 6. What Is pgAdmin?

pgAdmin is a graphical administration tool for PostgreSQL.

It allows users to:

- Connect to PostgreSQL servers.
    
- Create and manage databases.
    
- Create tables and other database objects.
    
- Execute SQL queries.
    
- View query results.
    
- Import and export data.
    

**Important distinction:** PostgreSQL stores and processes the data. pgAdmin is the graphical tool used to interact with PostgreSQL.

## 📊 7. What Is a Table?

A table stores related records in rows and columns.

Example:

|employee_id|employee_name|department|
|---|---|---|
|1|Ankit|Data Engineering|
|2|Priya|Analytics|

- **Row:** One complete record.
    
- **Column:** One attribute of a record.
    
- **Table:** A collection of related records.
    

## 🧱 8. What Is a Schema?

A schema is a namespace that organizes database objects such as tables, views, and functions.

PostgreSQL databases commonly have a schema named `public`.

A database and a schema are different: a PostgreSQL database can contain multiple schemas.

## ⌨️ 9. What Is SQL?

SQL stands for Structured Query Language.

It is used to define database objects and manipulate or retrieve data.

|Command|Purpose|
|---|---|
|`CREATE`|Create database objects|
|`INSERT`|Add records|
|`SELECT`|Retrieve records|
|`UPDATE`|Modify records|
|`DELETE`|Remove records|

## 🔢 10. What Is a Data Type?

A data type defines what kind of values a column can store.

|Data type|Example|
|---|---|
|`INTEGER`|`100`|
|`NUMERIC(10,2)`|`1250.75`|
|`TEXT`|`'Ankit'`|
|`BOOLEAN`|`TRUE`|
|`DATE`|`'2026-10-13'`|
|`TIMESTAMP`|`'2026-10-13 10:30:00'`|

## 🔄 11. Basic Database Workflow

1. Create or select a database.
    
2. Create a table.
    
3. Insert records.
    
4. Retrieve data using `SELECT`.
    
5. Check the results.
    

## 🧠 12. Key Takeaways

- PostgreSQL is a relational database management system.
    
- pgAdmin provides a graphical interface for managing PostgreSQL.
    
- SQL is used to create objects and manipulate or retrieve data.
    
- Tables organize records into rows and columns.
    
- Data types define which values columns can store.
    
- A database can contain multiple schemas and tables.

# 3. 💻 PostgreSQL SQL Code

Run each step in pgAdmin in the order shown. These examples are intended to be executable in PostgreSQL.

### 🧱 Step 1 — Create a database

Tool: pgAdmin → connect to the server → select `postgres` or another existing database → open Query Tool.

```
CREATE DATABASE practice_db;
```

- 📝 This creates a database named `practice_db`.
    
- ⚠️ If it already exists, skip this step or use a different name.
    
- 🚫 Do not execute `CREATE DATABASE` inside a transaction block.
    

### 🔌 Step 2 — Connect to `practice_db`

In pgAdmin, locate `practice_db` under Databases, right-click it, and open Query Tool.

```
SELECT current_database();
```

Expected result:

|current_database|
|---|
|practice_db|

### 🏗️ Step 3 — Create an employees table

```
CREATE TABLE employees (
    employee_id INTEGER,
    employee_name TEXT,
    department TEXT,
    salary NUMERIC(10, 2)
);
```

Explanation:

- `employee_id` stores an employee identifier.
    
- `employee_name` stores the employee's name.
    
- `department` stores the department.
    
- `salary` stores a decimal amount.
    

This first table is intentionally simple. We will add primary keys and other constraints later in the challenge.

### ➕ Step 4 — Insert employee records

```
INSERT INTO employees (
    employee_id,
    employee_name,
    department,
    salary
)
VALUES
    (1, 'Ankit', 'Data Engineering', 55000.00),
    (2, 'Priya', 'Analytics', 48000.00),
    (3, 'Rahul', 'IT Support', 42000.00);
```

Expected outcome: three records inserted.

### 🔍 Step 5 — Retrieve all records

```
SELECT *
FROM employees;
```

Expected result:

|employee_id|employee_name|department|salary|
|---|---|---|---|
|1|Ankit|Data Engineering|55000.00|
|2|Priya|Analytics|48000.00|
|3|Rahul|IT Support|42000.00|

### 🎯 Step 6 — Retrieve selected columns

```
SELECT employee_name, department
FROM employees;
```

This returns only the employee names and departments.

### 🧾 Step 7 — Inspect the table structure

```
SELECT
    column_name,
    data_type,
    is_nullable
FROM information_schema.columns
WHERE table_schema = 'public'
  AND table_name = 'employees'
ORDER BY ordinal_position;
```

This query shows each column's name, data type, and NULL allowance.

### 🔢 Step 8 — Count employee records

```
SELECT COUNT(*) AS total_employees
FROM employees;
```

# 🛠️ Day 1 Mini Project — Library Inventory Management System
## 🛠️ Step 1: Create the `books` Table

Run this SQL in pgAdmin's Query Tool after connecting to `library_db`.

```
CREATE TABLE books (
    book_id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    isbn VARCHAR(20) UNIQUE,
    title VARCHAR(150) NOT NULL,
    author VARCHAR(100) NOT NULL,
    category VARCHAR(50),
    publisher VARCHAR(100),
    publication_date DATE,
    price NUMERIC(10, 2) NOT NULL CHECK (price >= 0),
    quantity INTEGER NOT NULL DEFAULT 0 CHECK (quantity >= 0),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 📚 Step 2: Understand the Columns

|Column|Purpose|
|---|---|
|`book_id`|Unique ID automatically generated for each book|
|`isbn`|Unique book ISBN|
|`title`|Book title; required|
|`author`|Author's name; required|
|`category`|Book category|
|`publisher`|Publisher's name|
|`publication_date`|Date the book was published|
|`price`|Book price; cannot be negative|
|`quantity`|Number of available copies; defaults to zero|
|`created_at`|Timestamp when the record is created|

### 🔑 Why These Constraints Matter

- `PRIMARY KEY` ensures every book record has a unique identifier.
    
- `IDENTITY` automatically generates `book_id` values.
    
- `UNIQUE` prevents duplicate ISBN values.
    
- `NOT NULL` requires important values to be provided.
    
- `CHECK` prevents negative prices and quantities.
    
- `DEFAULT` provides an initial quantity of `0` when none is supplied.
    

## 🧪 Step 3: Verify the Table

```
SELECT
    column_name,
    data_type,
    is_nullable,
    column_default
FROM information_schema.columns
WHERE table_schema = 'public'
  AND table_name = 'books'
ORDER BY ordinal_position;
```
