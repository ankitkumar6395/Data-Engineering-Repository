# 📚 1. Study — Theory
 
## 📖 Topic 1: What Is SQL?
 
SQL stands for Structured Query Language. It is used to communicate with relational databases.
 
Data Engineers use SQL to retrieve, insert, update, delete, and transform data.
 
Example:
 
```
SELECT *
FROM employees;
```
 
This query retrieves all columns and rows from the `employees` table.
 
## 🗄️ Topic 2: What Is a Database?
 
A database is an organized collection of data.
 
For example, a company database may contain employee, customer, product, and order information.
 
```
company_db
├── employees
├── customers
├── products
└── orders
```
 
## 📋 Topic 3: Tables, Rows, and Columns
 
A table stores related data in rows and columns.
 
| employee\_id | employee\_name | department | salary |
| ------------ | -------------- | ---------- | ------ |
| 101          | Ankit          | IT         | 50000  |
| 102          | Rahul          | HR         | 42000  |
| 103          | Priya          | Finance    | 55000  |
 
- Table: A collection of related records.
- Row: One complete record.
- Column: One attribute, such as `department`.
- Value: An individual piece of data, such as `50000`.
 
 
## 🧩 Topic 4: SQL Command Categories
 
| Category | Purpose                     | Examples                     |
| -------- | --------------------------- | ---------------------------- |
| DDL      | Defines database structures | `CREATE`, `ALTER`, `DROP`    |
| DML      | Modifies data               | `INSERT`, `UPDATE`, `DELETE` |
| DQL      | Retrieves data              | `SELECT`                     |
| DCL      | Controls permissions        | `GRANT`, `REVOKE`            |
| TCL      | Manages transactions        | `COMMIT`, `ROLLBACK`         |
 
## 🚀 Topic 5: Why SQL Is Important for Data Engineers
 
SQL helps Data Engineers work with data stored in databases and data warehouses.
 
Common uses include:
 
- Extracting data from source tables.
- Transforming data into useful formats.
- Checking data quality.
- Loading data into target tables.
- Preparing datasets for analytics.

## 2. 📚 Study — Theory
 
### 🗄️ What is a database?
 
A database is an organized collection of data. For example, a company database might store employee details, department information, and project records.
 
```
CREATE DATABASE company_db;
```
 
This creates a database named `company_db`.
 
### 🧩 What is a schema?
 
A schema organizes database objects, such as tables and views.
 
MySQL note: In MySQL, `SCHEMA` and `DATABASE` are synonyms. You can use either term in statements such as `CREATE SCHEMA` and `CREATE DATABASE`.
 
```
CREATE SCHEMA company_db;
```
 
Use either the database or schema creation statement—not both with the same name unless you intentionally choose different names.
 
### 📋 What is a table?
 
A table stores related data in rows and columns.
 
Example: `employees`
 
| employee\_id | employee\_name | department |
| ------------ | -------------- | ---------- |
| 101          | Rahul          | IT         |
| 102          | Priya          | HR         |
| 103          | Aman           | Finance    |
 
- Row: One complete record, such as Rahul’s details.
- Column: One attribute, such as `employee_name`.
- Table: A collection of related records.
- Database: A container for related database objects.
 
 
### 🎯 Why does a Data Engineer need these concepts?
 
Data Engineers organize incoming data into databases and tables so it can be stored, queried, and used by analytics systems. A clear structure makes data easier to manage and understand.
 
### 🔍 Useful MySQL commands
 
| Command             | Purpose                              |
| ------------------- | ------------------------------------ |
| `CREATE DATABASE`   | Create a database                    |
| `SHOW DATABASES`    | List databases                       |
| `USE`               | Select a database                    |
| `CREATE TABLE`      | Create a table                       |
| `SHOW TABLES`       | List tables in the selected database |
| `DESCRIBE`          | Inspect a table's columns and types  |
| `SELECT DATABASE()` | Show the currently selected database |
| `DROP TABLE`        | Delete a table and its data          |
 
⚠️ `DROP TABLE` permanently removes the table and its data. Use it carefully.

## 2. 📚 Study — Theory
 
### 🔢 Numeric data types
 
| Data type      | Use                        | Example      |
| -------------- | -------------------------- | ------------ |
| `TINYINT`      | Small whole numbers        | `1`          |
| `INT`          | Whole numbers              | `1250`       |
| `BIGINT`       | Very large whole numbers   | `9000000000` |
| `DECIMAL(p,s)` | Exact decimal values       | `1250.75`    |
| `FLOAT`        | Approximate decimal values | `3.14`       |
 
💡 Important: Use `DECIMAL` for financial amounts when exact decimal representation matters. `FLOAT` is approximate and is better suited to values where small rounding differences are acceptable.
 
### 📝 Text data types
 
| Data type    | Use                  | Example             |
| ------------ | -------------------- | ------------------- |
| `CHAR(n)`    | Fixed-length text    | `'IN'`              |
| `VARCHAR(n)` | Variable-length text | `'Muzaffarnagar'`   |
| `TEXT`       | Longer text          | Product description |
 
Use `VARCHAR` for values such as email addresses, city names, and product names.
 
### 📅 Date and time data types
 
| Data type   | Stores                                                   | Example                 |
| ----------- | -------------------------------------------------------- | ----------------------- |
| `DATE`      | Date only                                                | `'2026-10-14'`          |
| `TIME`      | Time only                                                | `'14:30:00'`            |
| `DATETIME`  | Date and time                                            | `'2026-10-14 14:30:00'` |
| `TIMESTAMP` | Date and time with time-zone-related conversion behavior | `'2026-10-14 14:30:00'` |
 
`TIMESTAMP` and `DATETIME` behave differently. MySQL converts `TIMESTAMP` values between the session time zone and UTC, while `DATETIME` does not perform that conversion.
 
### 📐 Understanding `DECIMAL(p,s)`
 
In `DECIMAL(8,2)`:
 
- `8` is the maximum number of digits in total.
- `2` is the number of digits after the decimal point.
- Up to six digits can appear before the decimal point.
 
 
For example, `123456.78` fits the definition.
 
### 🧱 What defines a table's structure?
 
A table structure includes:
 
- 📌 Column names
- 🔢 Data types
- 🔒 Constraints such as `NOT NULL`
- 🔑 Keys and other column properties
- ⚙️ Default values
 
 
A well-designed structure helps represent data correctly and prevents unsuitable values from being stored.
 
### 🔍 MySQL commands for examining structure
 
```
DESCRIBE table_name;
```
 
Shows the table's columns and their properties.
 
```
SHOW CREATE TABLE table_name;
```
 
Shows the SQL definition of the table.
