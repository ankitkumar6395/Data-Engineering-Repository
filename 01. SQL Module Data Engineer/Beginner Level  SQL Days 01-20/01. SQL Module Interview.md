
# 🎯 SQL Chapter 1: Interview Questions and Answers
---
## 📘 Introduction to SQL for Data Engineers Completed ✅

### ❓ 1. What is SQL?

💡 SQL stands for Structured Query Language. It is used to communicate with relational databases.

### 🔤 2. What does SQL stand for?

💡 SQL stands for Structured Query Language.

### 🗄️ 3. What is a database?

💡 A database is an organized collection of data that can be stored, accessed, and managed.

### 📋 4. What is a table in SQL?

💡 A table stores related data in rows and columns.

### 🧾 5. What is a row in a database table?

💡 A row represents one complete record in a table.

### 📊 6. What is a column in a database table?

💡 A column represents a specific attribute, such as employee name, department, or salary.

### 🐬 7. What is MySQL?

💡 MySQL is a relational database management system that uses SQL to manage data.

### 💻 8. What is MySQL Workbench?

💡 MySQL Workbench is a graphical tool used to write, execute, and manage SQL queries and databases.

### 🔎 9. What is the purpose of the `SELECT` statement?

💡 The `SELECT` statement retrieves data from a table or another query source.

Example:

```
SELECT *
FROM employees;
```

### 🏗️ 10. What is the purpose of `CREATE DATABASE`?

💡 The `CREATE DATABASE` statement creates a new database.

Example:

```
CREATE DATABASE company_db;
```

### 🧩 11. What are the five main SQL command categories?

💡 The five commonly taught categories are:

- DDL: Defines database structures.
    
- DML: Modifies data.
    
- DQL: Retrieves data.
    
- DCL: Controls permissions.
    
- TCL: Manages transactions.
    

### 🚀 12. Why is SQL important for Data Engineers?

💡 SQL helps Data Engineers retrieve, transform, validate, and manage data stored in databases and data warehouses.

### 🛠️ 13. What did you create in your first SQL mini project?

💡 I created an employee database using MySQL. I created an employees table, inserted five employee records, and retrieved the records using the `SELECT` statement.

### 🧠 14. What is the difference between SQL and MySQL?

💡 SQL is a query language, whereas MySQL is a relational database management system that uses SQL.

### 📦 15. What information did you store in your employee table?

💡 I stored four fields: employee ID, employee name, department, and salary.

A database is an organized collection of data that can be stored, accessed, and managed efficiently.

# 🎯 Day 3 — Data Types & Table Structure Completed ✅

### ❓ 1. What are data types in MySQL?

Data types define what kind of values a column can store, such as numbers, text, dates, and times.

### 🔢 2. What is the difference between `INT` and `BIGINT`?

Both store integer values, but `BIGINT` supports a larger range than `INT`.

### 📝 3. What is the difference between `CHAR` and `VARCHAR`?

`CHAR` is designed for fixed-length strings, while `VARCHAR` stores variable-length strings.

### 💰 4. Why is `DECIMAL` used for financial values?

`DECIMAL` stores exact decimal values, making it suitable for prices and monetary amounts.

### 📊 5. What is the difference between `FLOAT` and `DECIMAL`?

`FLOAT` stores approximate numeric values, whereas `DECIMAL` stores exact decimal values within its defined precision and scale.

### 📅 6. What is the difference between `DATE` and `DATETIME`?

`DATE` stores only a date, while `DATETIME` stores both a date and a time.

### ⏰ 7. What is the purpose of the `TIME` data type?

`TIME` stores time values or time intervals.

### 🔢 8. What do precision and scale mean in `DECIMAL(10,2)`?

Precision is the total number of digits, which is 10. Scale is the number of digits after the decimal point, which is 2.

### 📱 9. Why should phone numbers generally be stored as text?

Phone numbers may contain leading zeros, plus signs, and formatting characters. They are identifiers rather than numbers used in calculations.

### 🧱 10. What is a table structure?

A table structure defines the column names, data types, and properties that determine how data is stored.

### 🔍 11. How can you check a table's structure in MySQL?

The `DESCRIBE` command displays a table's columns, data types, nullability, and key information.

### 📋 12. What does `SHOW CREATE TABLE` do?

It displays the SQL definition of a table, including its columns, data types, and constraints.

### 🔒 13. What does `NOT NULL` mean?

`NOT NULL` prevents a column from storing a `NULL` value.

### ☑️ 14. How does MySQL handle the `BOOLEAN` data type?

MySQL treats `BOOLEAN` as a synonym for `TINYINT(1)`. `TRUE` and `FALSE` are commonly represented by `1` and `0`.

### 🛠️ 15. Why is choosing the correct data type important?

It helps store information accurately, use storage efficiently, and reduce data conversion problems.

### 💡 16. What factors should you consider when selecting a data type?

Consider the kind of data, expected range or length, precision requirements, and whether the column can contain missing values.

### ⚠️ 17. What can happen if a value does not fit a column's data type?

MySQL may reject the value or handle it according to the data type and SQL mode. Appropriate validation helps prevent data quality issues.

### 🔄 18. What is the difference between `DATETIME` and `TIMESTAMP` in MySQL?

`DATETIME` does not automatically convert values between time zones. `TIMESTAMP` converts values between the session time zone and UTC.

### 🧮 19. Why is `DECIMAL` often preferred over `FLOAT` for prices?

`DECIMAL` represents decimal amounts exactly within its defined range, which is important when working with financial values.

### 🎯 20. How do data types support good database design?

They define valid representations for column values, improve data consistency, and make databases easier to maintain and use.

# 📘 Day 4 — INSERT: Loading Data Completed ✅

### ❓ 1. What is the purpose of the `INSERT` statement in a data pipeline?

It adds new records to a target table, allowing incoming data to be stored for downstream processing.

### 🔄 2. What is the difference between a full data load and an incremental data load?

A full load processes the complete dataset, while an incremental load processes only new or changed records.

### 🧩 3. What is the difference between a database error and a data quality issue?

A database error prevents or disrupts an operation. A data quality issue means the data is inaccurate, incomplete, inconsistent, or otherwise unsuitable, even if the database accepts it.

### 🔑 4. What is a primary key, and why does it matter during data loading?

A primary key uniquely identifies each row. Duplicate key values can cause an insert to fail and may indicate duplicate records in the incoming data.

### 🛡️ 5. How can you reduce the risk of inserting invalid data?

Validate the incoming values, check required fields and data types, enforce appropriate constraints, and review database errors.

### 📦 6. Why might a Data Engineer load data in batches?

Batch loading can improve efficiency when processing many records and makes it easier to organize and monitor a loading job.

### 🔁 7. What does idempotency mean in a data-loading workflow?

An operation is idempotent when repeating it produces the same final state rather than unintentionally duplicating or changing the result.

### ⚠️ 8. Why should you avoid blindly rerunning an insert script?

Rerunning it may insert duplicate records or trigger primary key errors. The workflow should have an appropriate strategy for retries and duplicate handling.

### 🧾 9. What information should be recorded when monitoring a data-loading job?

Useful information includes the execution time, number of records processed, number of failures, error details, and final job status.

### 🚀 10. How would you troubleshoot a failed data-loading operation?

I would inspect the MySQL error message, verify the selected database and table structure, check the input values and constraints, correct the issue, and rerun the operation safely.

## 📘 Day 5 — SELECT: Retrieving Data Completed ✅

### ❓ 1. What is a result set in SQL?

A result set is the collection of rows and columns returned by a query.

### 🔍 2. How does MySQL process a query that retrieves data?

MySQL parses and validates the query, determines an execution plan, accesses the required data, and returns the result.

### 🧠 3. What is the difference between logical query processing and the order in which a query is written?

SQL has a logical processing order that differs from its written clause order. Understanding it helps explain how the database interprets a query.

### 🏷️ 4. Can a column alias be used everywhere in the same query?

No. Alias visibility depends on the clause. For example, a `SELECT` alias can generally be used in `ORDER BY`, but not directly in `WHERE`.

### 🧮 5. What happens if an arithmetic expression uses a `NULL` value?

The result of most ordinary arithmetic expressions involving `NULL` is `NULL`, because the value is unknown.

### 📊 6. Why should a Data Engineer retrieve only the columns needed for a task?

It can reduce unnecessary data transfer and make queries easier to read and maintain.

### 🔎 7. What is the difference between a query that returns zero rows and a query that fails?

A query returning zero rows executes successfully but finds no rows to return. A failed query encounters an error and does not complete normally.

### 🧾 8. What is the difference between stored data and a calculated query result?

Stored data exists in database records. A calculated query result is computed when the query runs and does not automatically create a new stored column.

### ⚙️ 9. What is a query execution plan?

It describes how MySQL intends to execute a query, including how tables may be accessed and which indexes may be used. `EXPLAIN` can help inspect the plan.

### 🚀 10. How can you check whether a retrieval query is performing efficiently?

I would inspect its execution plan, review the amount of data being accessed, check index usage, and examine query execution performance with suitable diagnostic tools.

## 📘 Day 6 — WHERE: Filtering Data Completed ✅

### ❓ 1. What happens when a `WHERE` condition evaluates to `UNKNOWN`?

In SQL's three-valued logic, comparisons involving `NULL` often evaluate to `UNKNOWN`. A `WHERE` clause returns only rows for which its condition evaluates to `TRUE`.

### 🧠 2. What is SQL's three-valued logic?

SQL conditions can evaluate to `TRUE`, `FALSE`, or `UNKNOWN`. This is important when working with missing or unknown values.

### 🔤 3. Are text comparisons always case-sensitive in MySQL?

No. Case sensitivity depends on the collation used by the column or expression. Some collations are case-insensitive, while others are case-sensitive.

### 📅 4. Why should dates be compared using appropriate date values?

Appropriate date comparisons let MySQL compare chronological values correctly instead of relying on potentially misleading text comparisons.

### ⚙️ 5. Can filtering conditions affect query performance?

Yes. Selective conditions may reduce the number of rows processed by later operations. Suitable indexes can also help, depending on the query and execution plan.

### 🔍 6. What is a sargable condition?

A sargable condition is written in a way that allows the database optimizer to use an index efficiently when an appropriate index exists.

### 🧪 7. How would you validate a filtering query?

I would check the condition, inspect sample results, compare the returned records with the expected outcome, and test boundary cases.

### 🛡️ 8. Why is filtering useful in data quality checks?

It helps isolate suspicious or invalid records so that they can be investigated without examining the entire dataset manually.

### 📊 9. What is the difference between filtering data and deleting data?

Filtering controls which rows appear in a query result. Deleting data removes records from a table.

### 🚀 10. How would you investigate a query that returns unexpected records?

I would review the condition and data types, inspect the relevant records, check how `NULL` and text comparisons behave, and verify the results with targeted test cases.
