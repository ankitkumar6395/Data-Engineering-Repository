# 🎯 SQL for Data Engineers — Interview Questions & Answers 

## 📘 Day 1 — Introduction Completed ✅

### ❓ 1. What is SQL?

SQL stands for Structured Query Language. It is used to create, retrieve, modify, and manage data stored in relational databases.

### ❓ 2. What does SQL stand for?

SQL stands for Structured Query Language.

### ❓ 3. What is a database?

A database is an organized collection of data that can be stored, accessed, and managed efficiently.

### ❓ 4. What is a relational database?

A relational database stores data in tables made up of rows and columns. Tables can be connected through relationships between their columns.

### ❓ 5. What is a table in SQL?

A table is a database object that stores related data in rows and columns. For example, a table can store information about products, orders, or customers.

### ❓ 6. What is the difference between a row and a column?

A row represents one record, while a column represents a particular attribute of that record.

### ❓ 7. What are DDL, DML, and DQL?

- **DDL:** Data Definition Language, such as `CREATE` and `ALTER`.
    
- **DML:** Data Manipulation Language, such as `INSERT`, `UPDATE`, and `DELETE`.
    
- **DQL:** Data Query Language, commonly represented by `SELECT`.
    

### ❓ 8. What is the difference between SQL and MySQL?

SQL is a language used to work with relational databases. MySQL is a relational database management system that supports SQL.

### ❓ 9. What is a primary key?

A primary key uniquely identifies each row in a table. It cannot contain duplicate values or `NULL`.

### ❓ 10. Why is SQL important for Data Engineers?

Data Engineers use SQL to extract, transform, validate, and load data. It is also useful for investigating data quality issues and checking pipeline results.

### ❓ 1. What is the purpose of `CREATE DATABASE`?

It creates a new database.

```
CREATE DATABASE logistics_db;
```

### ❓ 2. What does the `USE` statement do in MySQL?

It selects the database to be used for subsequent statements.

```
USE logistics_db;
```

### ❓ 3. How do you list databases in MySQL?

Use `SHOW DATABASES`.

```
SHOW DATABASES;
```

### ❓ 4. How do you create a table?

Use `CREATE TABLE` and define its columns and data types.

```
CREATE TABLE delivery_routes (
    route_id INT PRIMARY KEY,
    route_name VARCHAR(100)
);
```

### ❓ 5. How do you list tables in the current database?

Use `SHOW TABLES`.

```
SHOW TABLES;
```

### ❓ 6. How do you inspect a table's column structure?

Use `DESCRIBE` or its short form, `DESC`.

```
DESCRIBE delivery_routes;
```

### ❓ 7. What is a schema in MySQL?

In MySQL, `SCHEMA` is generally synonymous with `DATABASE`. Both refer to a named collection of database objects.

### ❓ 8. How can you check which database is currently selected?

Use `SELECT DATABASE()`.

```
SELECT DATABASE();
```

### ❓ 9. What is the difference between `DROP TABLE` and `DROP DATABASE`?

`DROP TABLE` removes a specific table and its data. `DROP DATABASE` removes the database and its contained objects.

### ❓ 10. Why should you inspect a table before loading data into it?

Inspecting the structure helps confirm column names, data types, and constraints. This reduces errors during data loading and transformation.

## 📘 Day 3 — Data Types & Table Structure Completed ✅

### ❓ 1. Why are data types important in SQL?

Data types determine what kind of values a column can store. Choosing suitable types improves data accuracy, storage efficiency, and query reliability.

### ❓ 2. What is the difference between `INT` and `BIGINT`?

Both store integers, but `BIGINT` supports a much larger range of values than `INT`. Choose the type according to the expected data range.

### ❓ 3. What is the difference between `CHAR` and `VARCHAR`?

`CHAR` is designed for fixed-length character values, while `VARCHAR` stores variable-length character values. `VARCHAR` is often suitable for names and descriptions of varying lengths.

### ❓ 4. When would you use `TEXT`?

`TEXT` is useful for longer text content, such as comments, descriptions, or message bodies, when a regular `VARCHAR` column is not the preferred choice.

### ❓ 5. What is the difference between `DECIMAL` and `FLOAT`?

`DECIMAL` stores exact decimal values within its supported precision. `FLOAT` stores approximate numeric values. `DECIMAL` is usually preferred for financial amounts.

### ❓ 6. What is the difference between `DATE`, `TIME`, and `DATETIME`?

- `DATE` stores a calendar date.
    
- `TIME` stores a time value.
    
- `DATETIME` stores both a date and a time.
    

### ❓ 7. What does `DECIMAL(10,2)` mean?

It allows up to 10 digits in total, with 2 digits after the decimal point. For example, `12548.75` fits this definition.

### ❓ 8. How is a Boolean value represented in MySQL?

MySQL supports `BOOLEAN` as a synonym for `TINYINT(1)`. Conventionally, `0` represents false and `1` represents true.

### ❓ 9. How can you view a table's complete creation definition?

Use `SHOW CREATE TABLE`.

```
SHOW CREATE TABLE delivery_routes;
```

Replace the table name with the table you want to inspect.

### ❓ 10. What should you consider when selecting a column's data type?

Consider the expected values, numeric range, precision, text length, date requirements, and how the column will be queried. Avoid choosing a type that cannot accurately represent valid data.

## 📘 Day 4 — INSERT: Loading Data Completed ✅

### ❓ 1. What is the purpose of the `INSERT` statement?

`INSERT` adds new records to a table.

```
INSERT INTO delivery_routes (route_id, route_name)
VALUES (1, 'North Route');
```

### ❓ 2. Why is it good practice to specify column names in an `INSERT` statement?

It makes the intended column mapping explicit and reduces errors if the table structure changes.

### ❓ 3. How do you insert multiple rows in one statement?

Use multiple value groups separated by commas.

```
INSERT INTO delivery_routes (route_id, route_name)
VALUES
    (2, 'East Route'),
    (3, 'West Route');
```

### ❓ 4. What happens if you insert a duplicate primary key?

MySQL rejects the insert with a duplicate-key error unless the statement uses a suitable conflict-handling approach. Primary-key uniqueness is still enforced.

### ❓ 5. What happens if a required column is omitted?

If the column is `NOT NULL` and has no default value, MySQL generally rejects an insert that does not provide a valid value for it. The exact behavior can depend on SQL mode.

### ❓ 6. What is the difference between a full load and an incremental load?

A full load transfers the entire required dataset. An incremental load transfers only new or changed records since a previous load point.

### ❓ 7. What is batch loading?

Batch loading inserts or processes a group of records together instead of handling each record individually. It can improve efficiency for large data loads.

### ❓ 8. What is idempotency in data loading?

An operation is idempotent when repeating it produces the same intended final state without unintended additional effects. Data pipelines often use unique keys, upserts, or staging-and-replacement strategies to achieve this.

### ❓ 9. How would you troubleshoot a failed insert?

Check the SQL syntax, column names, data types, constraints, duplicate keys, and input values. Also inspect the error message and relevant database logs.

### ❓ 10. How can you verify that data was inserted correctly?

Query the inserted records and compare their values with the source data. For larger loads, compare row counts and relevant validation totals.

## 📘 Day 5 — SELECT: Retrieving Data Completed ✅

### ❓ 1. What is the purpose of `SELECT`?

`SELECT` retrieves data from one or more database tables.

```
SELECT route_name
FROM delivery_routes;
```

### ❓ 2. What does `SELECT *` do?

It returns all columns from the selected table or result source.

```
SELECT *
FROM delivery_routes;
```

### ❓ 3. Why might selecting specific columns be better than using `SELECT *`?

Selecting only the required columns can reduce unnecessary data transfer and make queries easier to understand. It is often preferable in production pipelines.

### ❓ 4. What is a column alias?

An alias gives a column or expression a temporary name in the query result.

```
SELECT route_name AS delivery_route
FROM delivery_routes;
```

### ❓ 5. Does an alias permanently rename a database column?

No. An alias changes the name shown in that query's result, not the underlying table definition.

### ❓ 6. Can you perform calculations inside a `SELECT` statement?

Yes. SQL supports arithmetic expressions in the result list.

```
SELECT quantity * unit_price AS total_value
FROM order_line_items;
```

### ❓ 7. What happens when an arithmetic expression uses `NULL`?

Usually, the result of the expression becomes `NULL` if a required operand is `NULL`. You can use functions such as `COALESCE` when an appropriate fallback value is required.

### ❓ 8. Can `SELECT` retrieve data without changing the source table?

Yes. A normal `SELECT` retrieves results without modifying the stored records.

### ❓ 9. What is a result set?

A result set is the collection of rows and columns returned by a query.

### ❓ 10. How can you investigate a slow `SELECT` query?

Start by checking the query conditions, selected columns, indexes, table sizes, and execution plan. In MySQL, `EXPLAIN` can help show how the database plans to execute a query.

```
EXPLAIN
SELECT route_name
FROM delivery_routes
WHERE route_id = 2;
```

## 📘 Day 6 — WHERE: Filtering Data Completed ✅

### ❓ 1. What is the purpose of the `WHERE` clause?

`WHERE` filters rows based on a condition so that only matching records are returned or affected.

### ❓ 2. What is the difference between `=` and `<>`?

`=` checks whether two values are equal. `<>` checks whether they are not equal. MySQL also supports `!=` as a not-equal operator.

### ❓ 3. How do you filter records using a numeric condition?

Use comparison operators such as `>`, `<`, `>=`, and `<=`.

```
SELECT *
FROM lab_equipment
WHERE replacement_cost > 5000;
```

### ❓ 4. How do you filter a column using a date?

Compare the date column with a date literal in a suitable format.

```
SELECT *
FROM lab_equipment
WHERE purchase_date >= '2026-01-01';
```

### ❓ 5. How do you filter rows where a column contains `NULL`?

Use `IS NULL`, not `= NULL`.

```
SELECT *
FROM lab_equipment
WHERE last_service_date IS NULL;
```

### ❓ 6. What is SQL's three-valued logic?

SQL conditions can evaluate to `TRUE`, `FALSE`, or `UNKNOWN`. Comparisons involving `NULL` often produce `UNKNOWN`, which does not pass a `WHERE` filter.

### ❓ 7. Does a `WHERE` condition permanently remove non-matching rows?

No. In a `SELECT` query, `WHERE` only filters the result. It does not delete the underlying records.

### ❓ 8. Can a `WHERE` clause filter text values?

Yes. Text comparisons can use operators such as `=` and `<>`. Case sensitivity depends on the column's collation and comparison rules.

### ❓ 9. What is a sargable condition?

A sargable condition is written in a way that can allow an index to help locate matching rows efficiently. For example, comparing an indexed date column directly to a date range is often more index-friendly than applying a function to the column.

### ❓ 10. How does filtering help data engineers?

Filtering helps isolate invalid records, investigate exceptions, inspect subsets of large datasets, and retrieve only the data needed for a transformation or report.

### ❓ 1. What is the purpose of logical operators in SQL?

Logical operators combine or reverse conditions. `AND`, `OR`, and `NOT` are commonly used in a `WHERE` clause.

`AND` requires all specified conditions to be true. `OR` requires at least one condition to be true.

### ❓ 3. What happens when one condition in an `AND` expression is false?

The entire expression is false, so the row does not pass the `WHERE` filter.

### ❓ 4. How does the `NOT` operator work?

`NOT` reverses a condition's truth value. However, `NOT` applied to `UNKNOWN` still produces `UNKNOWN`, so rows with relevant `NULL` values may not be returned.

### ❓ 5. Why are parentheses useful when combining `AND` and `OR`?

Parentheses make the intended grouping explicit and can change the query result. They help avoid logical mistakes.

### ❓ 6. Which operator has higher precedence: `AND` or `OR`?

`AND` has higher precedence than `OR`. Parentheses should be used when the intended order needs to be explicit.

### ❓ 7. How would you retrieve records that satisfy either of two conditions?

Use `OR`.

```

FROM pipeline_task_log

   OR duration_seconds > 120;
```

Yes. For example, a query can combine a text condition with a numeric condition, provided the comparisons are valid.

## 📘 Day 8 — UPDATE: Modifying Existing Data  Completed ✅

### ❓ 1. What is the purpose of the `UPDATE` statement?

`UPDATE` modifies existing values in a database table. It can change one column, multiple columns, or values across multiple rows.

### ❓ 2. Can one `UPDATE` statement modify multiple columns?

Yes. Multiple column assignments can be specified in the `SET` clause.

```sql
UPDATE cloud_resource_costs
SET monthly_cost = 950.00,
    cost_status = 'Verified'
WHERE resource_id = 2;
```

### ❓ 3. What happens if an `UPDATE` statement matches no rows?

No records are modified. This may happen if the target identifier does not exist or the `WHERE` condition is too restrictive.

### ❓ 4. How can you verify which records will be modified?

Run a `SELECT` query using the same `WHERE` condition before executing the update.

```sql
SELECT *
FROM cloud_resource_costs
WHERE cost_status = 'Needs Review';
```

### ❓ 5. Can an `UPDATE` statement use arithmetic expressions?

Yes. An expression can calculate a new value from the existing value.

```sql
UPDATE cloud_resource_costs
SET monthly_cost = monthly_cost * 1.05
WHERE resource_id = 1;
```

This increases the selected resource's monthly cost by 5%.

### ❓ 6. How can you update records using multiple conditions?

Use logical operators such as `AND` and `OR` in the `WHERE` clause to identify the intended records.

### ❓ 7. What is the difference between `UPDATE` and `INSERT`?

`UPDATE` modifies existing records, while `INSERT` adds new records to a table.

### ❓ 8. How can a transaction protect an update operation?

A transaction allows you to inspect changes before committing them. If the changes are incorrect and remain uncommitted, `ROLLBACK` can undo them in a transactional storage engine such as InnoDB.

### ❓ 9. What should you consider before updating a large table?

Verify the target records, check the filter conditions, consider indexes and transaction size, and understand the impact on concurrent queries. For important changes, ensure that an appropriate recovery plan exists.

### ❓ 10. How would you investigate an update that changed unexpected records?

Review the executed statement and its `WHERE` condition, inspect the affected rows, and check whether the changes remain inside an uncommitted transaction. If they do, `ROLLBACK` may be appropriate. If they were committed, recovery may require a backup or another approved recovery method.

## 📘 Day 9 — DELETE: Removing Data in SQL Completed ✅

### ❓ 1. What is the purpose of the `DELETE` statement?

The `DELETE` statement removes rows from a database table. It can remove specific rows using a `WHERE` condition or all rows when no condition is provided.

### ❓ 2. What happens if you execute `DELETE` without a `WHERE` clause?

All rows in the table are deleted, but the table structure remains.

### ❓ 3. Can deleted rows be recovered?

If the deletion is inside an uncommitted transaction on a transactional engine such as InnoDB, `ROLLBACK` can undo it. After a committed deletion, recovery generally requires a backup, binary logs, or another recovery mechanism.

### ❓ 4. What is the difference between `DELETE` and `TRUNCATE`?

`DELETE` can remove selected rows and supports `WHERE`. `TRUNCATE TABLE` removes all rows without a row-level filter and is generally faster for clearing a table.

### ❓ 5. What is the difference between `DELETE` and `DROP`?

`DELETE` removes rows but preserves the table definition. `DROP TABLE` removes the table itself, including its structure and data.

### ❓ 6. How can you preview the rows before deleting them?

Run a `SELECT` statement with the same filter conditions as the intended `DELETE`.

```
SELECT *
FROM import_queue
WHERE processing_status = 'Processed';
```

### ❓ 7. Can a `DELETE` statement use multiple conditions?

Yes. You can combine conditions using `AND`, `OR`, and parentheses to select the rows that should be removed.

### ❓ 8. How do foreign keys affect deletion?

A foreign key may prevent deleting a parent row when related child rows exist. Depending on the foreign-key configuration, cascading rules may also delete related rows.

### ❓ 9. Why should data engineers be careful when deleting staging data?

Staging records may be required for retries, debugging, reconciliation, or auditing. Engineers should verify retention rules and confirm that the records are no longer needed before deleting them.

### ❓ 10. How would you safely delete a large number of records?

First, verify the target rows and the deletion criteria. For large tables, consider transaction size, indexes, locking, backups, and whether deletion should be performed in controlled batches. Monitor the result and confirm that the correct records were removed.

## 📘 Day 10 — SQL Constraints: Maintaining Data Integrity Completed ✅

### ❓ 1. What are SQL constraints?

SQL constraints are rules applied to columns or tables to enforce data integrity. They help prevent invalid values and incorrect relationships from being stored.

### ❓ 2. Can a table have more than one constraint?

Yes. A table can use multiple constraints to enforce different rules, such as a primary key, unique tracking code, and check condition.

### ❓ 3. What is the difference between a primary key and a unique constraint?

A primary key uniquely identifies each row and cannot contain `NULL`. A unique constraint prevents duplicate key values but can allow multiple `NULL` values in MySQL.

### ❓ 4. What happens when a foreign key references a record that does not exist?

MySQL rejects the insert or update that violates the foreign-key constraint, unless the referenced value is permitted by the relationship's configuration, such as a nullable foreign-key column containing `NULL`.

### ❓ 5. Can a table have multiple unique constraints?

Yes. A table can have multiple unique constraints on different columns or combinations of columns.

### ❓ 6. What is the difference between `NOT NULL` and `DEFAULT`?

`NOT NULL` prevents a column from storing `NULL`. `DEFAULT` supplies a predefined value when a value is omitted or `DEFAULT` is specified in an insert.

### ❓ 7. What is the purpose of a `CHECK` constraint?

A `CHECK` constraint validates a condition on a row. For example, it can ensure that shipment weight is greater than zero.

### ❓ 8. What happens if an insert violates a constraint?

MySQL normally rejects the invalid insert or update and returns an error. The exact behavior depends on the constraint and statement being executed.

### ❓ 9. How do constraints help a Data Engineer?

They enforce data quality rules at the database level, help maintain relationships between datasets, and prevent certain invalid records from entering data pipelines.

### ❓ 10. Can constraints replace data validation in ETL pipelines?

No. Constraints are an important layer of data validation, but ETL pipelines may also need checks for business rules, source-data accuracy, freshness, completeness, and consistency across systems.

## 📘 Day 11 — ALTER TABLE: Modifying Table Structures Completed ✅

### ❓ 1. What is the purpose of `ALTER TABLE`?

`ALTER TABLE` modifies the structure of an existing table. It can add or remove columns, change column definitions, and add or remove certain constraints.

### ❓ 2. What is the difference between `MODIFY COLUMN` and `CHANGE COLUMN` in MySQL?

`MODIFY COLUMN` changes a column's definition without renaming it. `CHANGE COLUMN` can rename the column and also requires its new definition to be specified.

### ❓ 3. How do you add a new column to an existing table?

Use `ALTER TABLE` with `ADD COLUMN`.

```
ALTER TABLE shipment_tracking
ADD COLUMN carrier_reference VARCHAR(40);
```

### ❓ 4. How can you rename a column in MySQL?

Use `RENAME COLUMN` when only the name needs to change.

```
ALTER TABLE shipment_tracking
RENAME COLUMN tracking_code TO shipment_tracking_code;
```

### ❓ 5. What happens when you drop a column?

The column and its stored values are removed from the table. Check dependencies and backups before dropping a column that may be used by reports or applications.

### ❓ 6. Can you add a `NOT NULL` column to a table that already contains records?

Yes, but you must ensure that existing rows can receive valid values. Providing a suitable default is a common approach.

### ❓ 7. How do you add a constraint to an existing table?

Use `ALTER TABLE` with an appropriate clause, such as `ADD CONSTRAINT`.

```
ALTER TABLE shipment_tracking
ADD CONSTRAINT uq_tracking_code
UNIQUE (tracking_code);
```

Existing data must satisfy the constraint before MySQL can add it successfully.

### ❓ 8. Does `ALTER TABLE` modify the values in existing records?

It depends on the operation. Adding a column can give existing rows a default or `NULL`; renaming a column changes its name, and modifying a data type can affect how values are stored or interpreted.

### ❓ 9. How can you inspect a table after altering its structure?

Use `DESCRIBE` or `SHOW CREATE TABLE`.

```
DESCRIBE shipment_tracking;

SHOW CREATE TABLE shipment_tracking;
```

### ❓ 10. What should a Data Engineer consider before altering a production table?

Review existing data, constraints, indexes, dependencies, application queries, and pipeline requirements. Consider locking, table size, backup and recovery options, and whether the schema change is compatible with downstream systems.

## 📘 Day 12 — ORDER BY: Sorting SQL Query Results Completed ✅

### ❓ 1. What is the purpose of the `ORDER BY` clause?

`ORDER BY` sorts the rows returned by a query according to one or more columns or expressions.

### ❓ 2. What is the difference between `ASC` and `DESC`?

`ASC` sorts values in ascending order, while `DESC` sorts them in descending order. For numeric data, ascending means lowest to highest and descending means highest to lowest.

### ❓ 3. What happens if you omit the sorting direction?

MySQL uses ascending order by default when no direction is specified.

### ❓ 4. Can you sort query results using multiple columns?

Yes. MySQL sorts by the first column, then uses subsequent columns to order rows within matching values.

### ❓ 5. Does `ORDER BY` permanently change the order of stored rows?

No. It sorts the query result. It does not permanently rearrange the table's stored records.

### ❓ 6. Why might two executions of a query return tied records in a different order?

If rows have the same values for all specified sorting columns, their relative order is not guaranteed. Adding a unique tie-breaker can make the output deterministic.

### ❓ 7. Can you sort by a calculated expression?

Yes. You can sort by an arithmetic expression or a suitable alias defined in the `SELECT` list.

### ❓ 8. How does `ORDER BY` work with `LIMIT`?

`ORDER BY` determines the sorting order, and `LIMIT` restricts the number of returned rows. Together, they can retrieve the highest or lowest values from a dataset.

### ❓ 9. How does MySQL sort `NULL` values?

MySQL places `NULL` values before non-`NULL` values in ascending order and after them in descending order. An expression can be used to place missing values last when needed.

### ❓ 10. How can sorting affect query performance?

Sorting large datasets can require additional processing and memory or disk resources. Appropriate indexes may help, depending on the query and execution plan. `EXPLAIN` can help investigate the plan.

## 📘 Day 13 — DISTINCT & Column Aliases Completed ✅

### 🔍 1. What problem does `DISTINCT` solve in SQL?

`DISTINCT` removes duplicate rows from the result set. It is useful when identifying unique source systems, event types, categories, or combinations of attributes.

### 🧩 2. Does `DISTINCT` remove duplicate records from the original table?

No. It changes only the query output. The original table remains unchanged.

### 📊 3. How does `DISTINCT` behave when selecting two columns?

It considers both selected columns together. Two rows are duplicates only when the values in both selected columns match.

### 🏷️ 4. Why would a data engineer use a column alias?

An alias makes query results easier to understand, especially when column names are technical or when expressions are calculated. For example, `bytes_processed / 1024 AS kilobytes_processed` gives the calculated value a descriptive heading, assuming the source unit is bytes and the intended conversion is binary.

### ⚙️ 5. What is the difference between a column alias and renaming a table column?

A column alias changes the heading shown in a query result. Renaming a physical table column changes the table schema, typically using a statement such as `ALTER TABLE`.

### 🧮 6. Can `DISTINCT` be used inside an aggregate function?

Yes. For example, `COUNT(DISTINCT device_id)` counts unique non-`NULL` device IDs rather than counting every row.

### ⚠️ 7. How does `DISTINCT` treat `NULL` values?

For duplicate elimination, rows with `NULL` in the same selected position can collapse into one distinct result. This does not mean `NULL` equals `NULL` in ordinary SQL comparisons.

### 🧠 8. What happens when two rows share a provider name but have different environments?

With `SELECT DISTINCT provider_name, environment_name`, both combinations appear because the environment values differ.

### 🛠️ 9. Can an alias be used in `ORDER BY`?

Yes. In MySQL, a column alias defined in the `SELECT` list can generally be referenced in `ORDER BY`.

```
SELECT records_per_day * 2 AS projected_records
FROM integration_registry
ORDER BY projected_records DESC;
```

### 🚀 10. What should a data engineer consider before using `DISTINCT` on a large dataset?

First, determine whether duplicate elimination is actually required. `DISTINCT` can need extra memory or sorting/hash processing, depending on the query plan and indexes. If the goal is to count unique values, `COUNT(DISTINCT ...)` may express the requirement more directly.

##  📘 Day 14 — IN, BETWEEN & NULL Completed ✅
### 🔍 1. What is the main advantage of using `IN`?

`IN` allows a query to check a value against multiple possible values in a concise and readable way.

### 🧮 2. Are the boundaries included in `BETWEEN`?

Yes. `BETWEEN 10 AND 20` includes both `10` and `20`.

### 📅 3. What should you consider when using `BETWEEN` with a `DATETIME` column?

The endpoints are inclusive, but a date literal such as `'2026-10-21'` represents midnight at the start of that date. For a full-day timestamp range, use `>=` the starting date and `<` the next date.

### 🕳️ 4. Why is `IS NULL` necessary?

SQL uses three-valued logic: true, false, and unknown. Ordinary equality comparisons with `NULL` do not return true, so `IS NULL` is the correct way to identify missing values.

### ⚖️ 5. What is the difference between `NULL`, zero, and an empty string?

- `NULL`: a missing or unknown value.
    
- `0`: a numeric value.
    
- `''`: an empty text value.
    

They represent different things and should not be treated as interchangeable.

### 🚫 6. What is a potential problem with `NOT IN`?

If the list being checked contains `NULL`, the comparison may evaluate to unknown for otherwise non-matching values. This can cause expected rows to be excluded. Ensure the exclusion list contains no unexpected `NULL` values or use an appropriate alternative, such as `NOT EXISTS`.

### 🧪 7. Can `BETWEEN` be used with text columns?

Yes. It can compare text values according to the database's comparison and collation rules. However, for ordinary category selection, `IN` is often clearer.

### 🔗 8. Can `IN`, `BETWEEN`, and `IS NULL` be used in one query?

Yes. You can combine them with `AND` and `OR` to apply multiple filtering conditions.

### 📊 9. How can a data engineer count missing values in a column?

One approach is:

```
SELECT
    COUNT(*) - COUNT(delivery_contact) AS missing_contacts
FROM logistics_manifest;
```

`COUNT(*)` counts all rows, whereas `COUNT(delivery_contact)` excludes rows where the contact is `NULL`.

### 🛠️ 10. How would you find records where a required field is missing and the status belongs to a selected list?

Use `IS NULL` with `IN`:

```
SELECT *
FROM some_table
WHERE processing_status IN ('Pending', 'Failed')
  AND required_reference IS NULL;
```

## 📘 Day 15 — Aggregate Functions Completed ✅

### 🔢 1. What are aggregate functions in SQL?

Aggregate functions perform calculations across multiple rows and return a summary value, such as a count, total, average, minimum, or maximum.

### 📊 2. What is the difference between `COUNT(*)` and `COUNT(column_name)`?

`COUNT(*)` counts every row, whereas `COUNT(column_name)` counts only rows where the specified column is not `NULL`.

### 💰 3. How does `SUM()` handle `NULL` values?

`SUM()` ignores `NULL` values. It adds the available numeric values without treating missing values as zero.

### 🧮 4. How is `AVG()` calculated?

`AVG()` divides the sum of non-`NULL` numeric values by the number of non-`NULL` values.

### 📉 5. What is the difference between `MIN()` and `MAX()`?

`MIN()` returns the smallest available value, while `MAX()` returns the largest available value.

### 🕳️ 6. What does `COUNT(DISTINCT column_name)` do?

It counts the unique, non-`NULL` values in a column.

### ⚠️ 7. What happens when an aggregate function receives no qualifying rows?

`COUNT(*)` returns `0`. `SUM()`, `AVG()`, `MIN()`, and `MAX()` generally return `NULL` when there are no qualifying non-`NULL` values.

### 🔍 8. Can aggregate functions be used with `WHERE`?

Yes. `WHERE` filters individual rows before the aggregate functions calculate their results.

```
SELECT SUM(monthly_cost) AS production_cost
FROM cloud_resource_billing
WHERE environment_name = 'Production';
```

### 🧠 9. Why might `AVG(column)` differ from the average calculated by a report?

Possible reasons include missing values, filters, duplicate records, different calculation rules, or incorrect data types. The calculation should match the intended business definition.

### 🚀 10. Why are aggregate functions important in data engineering?

They help validate row counts, calculate totals, measure data completeness, monitor pipeline metrics, and generate summaries for reporting systems.

## 📘 Day 16 — GROUP BY Completed ✅

### 🔍 1. What is the purpose of `GROUP BY`?

`GROUP BY` organises rows with matching values in specified columns into groups. Aggregate functions can then calculate a summary for each group.

### 🧮 2. Can `GROUP BY` be used without aggregate functions?

Yes. It can return unique combinations of grouped columns, although `SELECT DISTINCT` is often clearer when duplicate elimination is the only objective.

### 📊 3. What happens when you group by two columns?

SQL creates a separate group for each unique combination of values in those columns.

### ⚖️ 4. What is the difference between `WHERE` and `GROUP BY`?

`WHERE` filters individual rows before grouping. `GROUP BY` organises the remaining rows into groups for summary calculations.

### 🕳️ 5. How does `GROUP BY` handle `NULL` values?

Rows with `NULL` in the same grouping column are placed into one group. Aggregate functions still handle `NULL` values in their own arguments according to their individual rules.

### ⚠️ 6. Why can a query fail when selecting a column that is not in `GROUP BY`?

With MySQL's `ONLY_FULL_GROUP_BY` mode, a selected column must generally be grouped, aggregated, or functionally dependent on the grouped columns. Otherwise, MySQL rejects the query because the correct value for each group is ambiguous.

### 📈 7. How would you calculate the total transaction value for each payment channel?

```
SELECT
    payment_channel,
    SUM(transaction_amount) AS total_amount
FROM transaction_log
GROUP BY payment_channel;
```

This returns one total per payment channel.

### 🔢 8. How can you count failed pipeline executions by pipeline?

```
SELECT
    pipeline_name,
    COUNT(*) AS failed_runs
FROM pipeline_execution_metrics
WHERE execution_status = 'Failed'
GROUP BY pipeline_name;
```

The `WHERE` clause selects failed executions before the grouping and counting take place.

### 🧠 9. What is the difference between `GROUP BY` and `ORDER BY`?

`GROUP BY` organises rows into groups for aggregation. `ORDER BY` sorts the resulting rows. They can be used together in the same query.

### 🚀 10. Why is `GROUP BY` important in data engineering?

It supports pipeline monitoring, batch summaries, data-quality reports, workload analysis, operational metrics, and reconciliation between source and destination datasets.

### ❓ Q1. What is the purpose of `HAVING`?

✅ Answer: It filters groups after `GROUP BY`, often using aggregate conditions.

### ❓ Q2. Can you use `COUNT()` inside `HAVING`?

✅ Answer: Yes, for example:

```
SELECT delivery_partner, COUNT(*) AS total_orders
FROM delivery_orders
GROUP BY delivery_partner
HAVING COUNT(*) >= 5;
```

### ❓ Q3. Can `WHERE` and `HAVING` be used together?

✅ Answer: Yes. `WHERE` filters rows before grouping, while `HAVING` filters groups after aggregation.
