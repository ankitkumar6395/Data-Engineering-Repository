## Chapter 1: Introduction to SQL Completed ✅
Goal: Learn the SQL fundamentals required for a Data Engineer role 
### INTERVIEW QUESTIONS + ANSWERS
***
### 1. What is SQL?
SQL is a language used to communicate with relational databases.
 
### 2. What does SQL stand for?
Structured Query Language.
 
### 3. What is a database?
A database is an organized collection of data.
### 4. What is a table?
A table stores related data in rows and columns.
### 5. What is a row?
A row represents one complete record.
### 6. What is a column?
A column represents an attribute of a table.
### 7. What is MySQL?
MySQL is a relational database management system that uses SQL.
### 8 .What does SELECT do?
It retrieves data from a table or other query source.
 
### 9. What is the purpose of CREATE DATABASE?
It creates a new database.
 
### 10. Why is SQL important for Data Engineers?
SQL helps Data Engineers retrieve, transform, validate, and manage data.
