
# 🎯 SQL Chapter 1: Interview Questions and Answers
---
## 📘 Introduction to SQL for Data Engineers Completed ✅

### ❓ 1. What is SQL?

💡 SQL stands for Structured Query Language. It is used to communicate with relational databases.

### 🔤 2. What does SQL stand for?

💡 SQL stands for Structured Query Language.

### 🗄️ 3. What is a database?

💡 A database is an organized collection of data that can be stored, accessed, and managed.

### 📋 4. What is a table in SQL?

💡 A table stores related data in rows and columns.

### 🧾 5. What is a row in a database table?

💡 A row represents one complete record in a table.

### 📊 6. What is a column in a database table?

💡 A column represents a specific attribute, such as employee name, department, or salary.

### 🐬 7. What is MySQL?

💡 MySQL is a relational database management system that uses SQL to manage data.

### 💻 8. What is MySQL Workbench?

💡 MySQL Workbench is a graphical tool used to write, execute, and manage SQL queries and databases.

### 🔎 9. What is the purpose of the `SELECT` statement?

💡 The `SELECT` statement retrieves data from a table or another query source.

Example:

```
SELECT *
FROM employees;
```

### 🏗️ 10. What is the purpose of `CREATE DATABASE`?

💡 The `CREATE DATABASE` statement creates a new database.

Example:

```
CREATE DATABASE company_db;
```

### 🧩 11. What are the five main SQL command categories?

💡 The five commonly taught categories are:

- DDL: Defines database structures.
    
- DML: Modifies data.
    
- DQL: Retrieves data.
    
- DCL: Controls permissions.
    
- TCL: Manages transactions.
    

### 🚀 12. Why is SQL important for Data Engineers?

💡 SQL helps Data Engineers retrieve, transform, validate, and manage data stored in databases and data warehouses.

### 🛠️ 13. What did you create in your first SQL mini project?

💡 I created an employee database using MySQL. I created an employees table, inserted five employee records, and retrieved the records using the `SELECT` statement.

### 🧠 14. What is the difference between SQL and MySQL?

💡 SQL is a query language, whereas MySQL is a relational database management system that uses SQL.

### 📦 15. What information did you store in your employee table?

💡 I stored four fields: employee ID, employee name, department, and salary.

# 🎯 Day 2 — Databases, Schemas & Tables Completed ✅

### ❓ 1. What is a database?

A database is an organized collection of data that can be stored, accessed, and managed efficiently.

### ❓ 2. What is a schema in MySQL?

A schema organizes database objects. In MySQL, the terms schema and database are used interchangeably.

### ❓ 3. What is a table in SQL?

A table stores related data in rows and columns.

### ❓ 4. What is the difference between a row and a column?

A row represents one record, while a column represents a particular attribute.

### ❓ 5. How do you create a database in MySQL?

```
CREATE DATABASE company_db;
```

The `CREATE DATABASE` command creates a new database.

### ❓ 6. How do you select a database?

```
USE company_db;
```

The `USE` command selects the database for the current session.

### ❓ 7. How do you display all databases?

```
SHOW DATABASES;
```

### ❓ 8. How do you create a table in MySQL?

```
CREATE TABLE employees (
    employee_id INT,
    employee_name VARCHAR(100),
    department VARCHAR(50)
);
```

### ❓ 9. How do you display all tables in the selected database?

```
SHOW TABLES;
```

### ❓ 10. How do you check the structure of a table?

```
DESCRIBE employees;
```

### ❓ 11. What does `SELECT DATABASE()` do?

It displays the name of the database currently selected in the session.

### ❓ 12. Why are databases and tables important for Data Engineers?

They help Data Engineers organize and store data so it can be used in data pipelines, analytics, and reporting.

### ❓ 13. What is the difference between MySQL Server and MySQL Workbench?

MySQL Server stores and manages data, while MySQL Workbench provides a graphical interface for executing SQL queries and managing database objects.

### ❓ 14. Which tables did you create in your Day 2 mini project?

I created `employees` and `departments` tables inside the `company_project_db` database.

### ❓ 15. Which SQL commands did you learn in Day 2?

I learned `CREATE DATABASE`, `USE`, `SHOW DATABASES`, `CREATE TABLE`, `SHOW TABLES`, `DESCRIBE`, and `SELECT DATABASE()`.

# 🎯 Day 3 — Data Types & Table Structure Completed ✅

### ❓ 1. What are data types in MySQL?

Data types define what kind of values a column can store, such as numbers, text, dates, and times.

### 🔢 2. What is the difference between `INT` and `BIGINT`?

Both store integer values, but `BIGINT` supports a larger range than `INT`.

### 📝 3. What is the difference between `CHAR` and `VARCHAR`?

`CHAR` is designed for fixed-length strings, while `VARCHAR` stores variable-length strings.

### 💰 4. Why is `DECIMAL` used for financial values?

`DECIMAL` stores exact decimal values, making it suitable for prices and monetary amounts.

### 📊 5. What is the difference between `FLOAT` and `DECIMAL`?

`FLOAT` stores approximate numeric values, whereas `DECIMAL` stores exact decimal values within its defined precision and scale.

### 📅 6. What is the difference between `DATE` and `DATETIME`?

`DATE` stores only a date, while `DATETIME` stores both a date and a time.

### ⏰ 7. What is the purpose of the `TIME` data type?

`TIME` stores time values or time intervals.

### 🔢 8. What do precision and scale mean in `DECIMAL(10,2)`?

Precision is the total number of digits, which is 10. Scale is the number of digits after the decimal point, which is 2.

### 📱 9. Why should phone numbers generally be stored as text?

Phone numbers may contain leading zeros, plus signs, and formatting characters. They are identifiers rather than numbers used in calculations.

### 🧱 10. What is a table structure?

A table structure defines the column names, data types, and properties that determine how data is stored.

### 🔍 11. How can you check a table's structure in MySQL?

The `DESCRIBE` command displays a table's columns, data types, nullability, and key information.

### 📋 12. What does `SHOW CREATE TABLE` do?

It displays the SQL definition of a table, including its columns, data types, and constraints.

### 🔒 13. What does `NOT NULL` mean?

`NOT NULL` prevents a column from storing a `NULL` value.

### ☑️ 14. How does MySQL handle the `BOOLEAN` data type?

MySQL treats `BOOLEAN` as a synonym for `TINYINT(1)`. `TRUE` and `FALSE` are commonly represented by `1` and `0`.

### 🛠️ 15. Why is choosing the correct data type important?

It helps store information accurately, use storage efficiently, and reduce data conversion problems.

### 💡 16. What factors should you consider when selecting a data type?

Consider the kind of data, expected range or length, precision requirements, and whether the column can contain missing values.

### ⚠️ 17. What can happen if a value does not fit a column's data type?

MySQL may reject the value or handle it according to the data type and SQL mode. Appropriate validation helps prevent data quality issues.

### 🔄 18. What is the difference between `DATETIME` and `TIMESTAMP` in MySQL?

`DATETIME` does not automatically convert values between time zones. `TIMESTAMP` converts values between the session time zone and UTC.

### 🧮 19. Why is `DECIMAL` often preferred over `FLOAT` for prices?

`DECIMAL` represents decimal amounts exactly within its defined range, which is important when working with financial values.

### 🎯 20. How do data types support good database design?

They define valid representations for column values, improve data consistency, and make databases easier to maintain and use.
