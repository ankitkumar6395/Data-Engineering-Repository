# 🎯 Day 1 — Interview Questions & Answers 

## 🗄️ Chapter 1: Introduction to PostgreSQL and pgAdmin Completed ✅


🐘 Q1. What is PostgreSQL?

✅ Answer: PostgreSQL is an open-source relational database management system (RDBMS) used to store, retrieve, and manage structured data using SQL.

🗄️ Q2. What is a database?

✅ Answer: A database is an organized collection of data that can be stored, accessed, updated, and managed efficiently.

⚙️ Q3. What is a DBMS?

✅ Answer: A Database Management System (DBMS) is software used to create, manage, retrieve, and maintain databases.

🔗 Q4. What is an RDBMS?

✅ Answer: An RDBMS stores data in tables consisting of rows and columns. It can establish relationships between tables using keys.

🖥️ Q5. What is pgAdmin?

✅ Answer: pgAdmin is a graphical administration tool used to connect to PostgreSQL, execute SQL queries, and manage database objects.

⚖️ Q6. What is the difference between PostgreSQL and pgAdmin?

✅ Answer:

- PostgreSQL: Stores and processes data.
    
- pgAdmin: Provides a graphical interface for managing PostgreSQL.
    

📊 Q7. What is a table in a database?

✅ Answer: A table organizes related data into rows and columns. For example, an `employees` table can store employee IDs, names, departments, and salaries.

📋 Q8. What is the difference between a row and a column?

✅ Answer:

- Row: Represents one complete record.
    
- Column: Represents one attribute of a record.
    

⌨️ Q9. What is SQL?

✅ Answer: SQL stands for Structured Query Language. It is used to create database objects and insert, retrieve, update, and delete data in relational databases.

🔢 Q10. What is a data type in PostgreSQL?

✅ Answer: A data type defines the kind of value a column can store. Examples include `INTEGER`, `TEXT`, `NUMERIC`, `BOOLEAN`, and `DATE`.

🧱 Q11. What is a schema in PostgreSQL?

✅ Answer: A schema is a namespace that organizes database objects such as tables, views, and functions within a database.

🏗️ Q12. Which SQL command is used to create a database?

✅ Answer: The `CREATE DATABASE` command creates a new database.

```
CREATE DATABASE practice_db;
```

➕ Q13. Which SQL command is used to insert data into a table?

✅ Answer: The `INSERT INTO` command adds new records to a table.

```
INSERT INTO employees
    (employee_id, employee_name, department, salary)
VALUES
    (1, 'Ankit', 'Data Engineering', 55000.00);
```

🔍 Q14. Which SQL command is used to retrieve data?

✅ Answer: The `SELECT` command retrieves data from a table.

```
SELECT *
FROM employees;
```

🔢 Q15. What does `SELECT *` mean in SQL?

✅ Answer: `SELECT *` retrieves all columns from the specified table or query result.
