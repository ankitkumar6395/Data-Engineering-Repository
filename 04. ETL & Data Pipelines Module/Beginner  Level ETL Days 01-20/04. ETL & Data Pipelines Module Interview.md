
# 🎯 ETL & Data Pipelines — Interview Questions

## 📘 Day 1: Introduction to ETL Completed ✅

### ❓ 1. What is ETL?

ETL stands for **Extract, Transform, and Load**. It is a process used to collect data from different sources, transform it into a suitable format, and load it into a destination system.

### ❓ 2. What are the three steps of ETL?

- 📥 **Extract:** Collect data from different sources.
    
- 🔧 **Transform:** Clean and process the data.
    
- 💾 **Load:** Store the processed data in a destination.
    

### ❓ 3. What is data extraction?

Data extraction is the process of collecting data from sources such as CSV files, Excel files, databases, JSON files, and APIs.

### ❓ 4. What is data transformation?

Data transformation is the process of converting raw data into a clean and useful format. It includes removing duplicates, handling missing values, changing data types, and filtering records.

### ❓ 5. What is data loading?

Data loading is the process of storing transformed data in a destination, such as MySQL, PostgreSQL, a data warehouse, or a data lake.

### ❓ 6. Why is ETL important in Data Engineering?

ETL helps Data Engineers collect data from different sources, improve data quality, and prepare reliable data for reporting, analytics, and business applications.

### ❓ 7. What are some common data sources used in ETL?

Common data sources include CSV files, Excel files, JSON files, databases, and APIs.

### ❓ 8. What problems can occur in raw data?

Raw data may contain missing values, duplicate records, incorrect data types, invalid values, and inconsistent formats. ETL processes help identify and address these problems.

### ❓ 9. Can you explain ETL with a real-world example?

An e-commerce company can extract customer orders from CSV files, clean and validate the records using Python, and load the processed data into MySQL for reporting.

### ❓ 10. What is the difference between raw data and transformed data?

Raw data is the original data collected from a source. Transformed data has been processed to meet specific requirements, such as removing duplicates, correcting formats, or calculating new values.

### ❓ 11. Which tools can be used to build an ETL pipeline?

Python, Pandas, SQL, MySQL, Apache Airflow, and cloud services can be used to build ETL pipelines. The choice depends on the project's requirements.

### ❓ 12. What is the basic ETL flow?

`Data Source → Extract → Transform → Load → Destination`

## 📗 Day 2: Data Pipeline Fundamentals Completed ✅

### ❓ 1. What is a data pipeline?

A data pipeline is a sequence of steps used to move data from a source to a destination. It may also transform, validate, and process the data along the way.

### ❓ 2. What are the main components of a data pipeline?

Common components include data sources, extraction, transformation, validation, loading, and monitoring. The exact components depend on the pipeline's design.

### ❓ 3. What is the difference between ETL and a data pipeline?

ETL is a specific process involving extraction, transformation, and loading. A data pipeline is a broader sequence of data-processing steps and may use ETL, ELT, streaming, or other approaches.

### ❓ 4. What is batch processing?

Batch processing means processing a group of records together, usually at scheduled intervals or when a batch becomes available.

**Example:** Processing all daily sales records at midnight.

### ❓ 5. What is streaming processing?

Streaming processing handles incoming data continuously or in small events as the data arrives.

**Example:** Processing payment events as customers make purchases.

### ❓ 6. What is the difference between batch and streaming processing?

Batch processing handles data in groups, while streaming processing handles incoming events continuously or in small increments. Batch processing is useful for scheduled jobs, whereas streaming is useful when data needs to be processed with low delay.

### ❓ 7. Why is data validation important in a pipeline?

Data validation checks whether records meet expected rules before they are used or loaded into a destination. It helps identify missing fields, invalid quantities, incorrect prices, and other data quality issues.

### ❓ 8. What is data pipeline monitoring?

Data pipeline monitoring means tracking pipeline execution, failures, processing time, and other important metrics. It helps Data Engineers detect problems and maintain reliable data processing.

### ❓ 9. What happens when a pipeline receives invalid records?

The pipeline can reject invalid records, record the reasons for rejection, and continue processing valid records when appropriate. The handling strategy depends on the business rules.

### ❓ 10. Can you explain a data pipeline with a real-world example?

An e-commerce company can read sales orders from a file, validate product names and prices, calculate order amounts, and load valid records into a database for reporting.

### ❓ 11. Why do companies automate data pipelines?

Companies automate data pipelines to reduce manual work, process data consistently, save time, and make data available to downstream systems more reliably.

### ❓ 12. What was the objective of your Day 2 mini project?

The objective was to design an e-commerce order processing pipeline using Python. It involved validating order records, separating invalid orders, calculating order amounts, calculating total revenue, and generating a daily report.

### ❓ 13. How do you calculate the total amount of an order?

Multiply the quantity by the unit price.

**Formula:** `Total Amount = Quantity × Unit Price`

For example, if a customer buys two laptops at ₹45,000 each, the total amount is ₹90,000.

### ❓ 14. What is the role of Python in a data pipeline?

Python can automate data extraction, transformation, validation, and loading. Libraries such as Pandas can also help process structured data efficiently.

### ❓ 15. What is the difference between a data source and a destination?

A data source provides the input data, while a destination receives the processed data.

**Example:** A CSV file can be the source, and a MySQL database can be the destination.
