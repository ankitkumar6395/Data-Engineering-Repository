## Day 1: Introduction to Workflow Orchestration 
### 1. What is workflow orchestration?
Workflow orchestration is the process of coordinating and managing multiple tasks, their dependencies, scheduling, and execution.
### 2. What is a workflow?
A workflow is a sequence of tasks that work together to complete a particular process.
### 3. What is a task?
A task is an individual unit of work within a workflow.
### 4. What is a data pipeline?
A data pipeline is a sequence of processes used to move and transform data from a source to a destination.
### 5. What is the difference between automation and orchestration?
Automation automatically executes a task, while orchestration coordinates multiple tasks and manages their dependencies, scheduling, and execution.
### 6. Why is orchestration important in data engineering?
It helps data engineers automate pipelines, manage dependencies, schedule workflows, monitor execution, and handle failures.
### 7. Name some workflow orchestration technologies.
Apache Airflow, Prefect, and Dagster are examples of workflow orchestration technologies.
### 8. What is Apache Airflow?
Apache Airflow is an open-source platform used to develop, schedule, and monitor workflows.

### 10. Why should tasks have dependencies?  
Dependencies ensure that tasks execute in the required order and that a task does not run before its required previous task has completed.
