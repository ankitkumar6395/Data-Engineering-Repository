# Beginner Level SQL

## Data Engineering – Beginner Module

Welcome to the Beginner Level SQL module of the Data Engineering Repository.

This module contains daily SQL classes, hands-on coding practice, and real-world mini projects to build a strong foundation in SQL for Data Engineering.

## Topics Covered

- SQL Fundamentals
- Database and Table Creation
- INSERT, UPDATE, and DELETE
- SELECT, WHERE, and ORDER BY
- DISTINCT, LIMIT, and Filtering
- Aggregate Functions
- GROUP BY and HAVING
- SQL JOINs
- Subqueries
- NULL Handling and CASE
- SQL String Functions
- Data Cleaning and Reporting

## Daily Classes

This folder contains day-wise SQL practice files, starting from Day 01 and progressing through the beginner-level topics.

## Tools Used

- MySQL
- MySQL Workbench
- GitHub

## Learning Goal

Build practical SQL skills, understand relational databases, write clean queries, and prepare for real-world Data Engineering tasks.
