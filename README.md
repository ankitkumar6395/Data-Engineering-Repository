# 📅 DAILY WORKFLOW

Every day follows the same structure.

## 1. 📚 STUDY

Learn the day's Data Engineering concepts and theory.

## 2. 💻 CODE

Practice the day's concepts with code.

## 3. 🧪 10 PRACTICE QUESTIONS

Solve 10 questions based on the day's topics.

## 4. 🛠️ MINI PROJECT

Build one different small real-world project using the day's concepts.

## 5. 🎯 INTERVIEW QUESTIONS + ANSWERS

Practice Data Engineering interview questions and answers.
